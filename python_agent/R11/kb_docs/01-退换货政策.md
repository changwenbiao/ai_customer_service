# 退换货政策

## 一、适用范围

本政策适用于平台自营及平台监管的第三方店铺商品。生鲜、定制、虚拟商品等特殊品类另有专项规则，见文末「不支持退货的情形」。

## 二、7 天无理由退货

- 起算时间：自签收次日起 **7 个自然日**内。
- 商品要求：商品完好、配件齐全、包装完整、不影响二次销售。
- 运费承担：无理由退货的 **退货运费由买家承担**；订单含运费险的，按运费险规则赔付。
- 赠品处理：赠品需一并退回，未退回的按赠品市场价扣减退款金额。
- 不支持品类：定制商品、生鲜食品、内衣裤及贴身衣物、已激活的数码产品、已拆封的音像制品、个人护理用品。

## 三、15 天质量问题退换

- 起算时间：自签收次日起 **15 个自然日**内。
- 适用情形：商品存在质量缺陷、功能故障、与描述严重不符。
- 运费承担：**商家承担往返运费**。
- 凭证要求：需提供商品照片或视频，大家电需提供故障视频。
- 处理方式：可退可换，买家可自行选择。

## 四、大家电三包

- 签收后 **30 日内**出现性能故障，可选择换货。
- 整机保修 **1 年**，主要部件保修 **3 年**，自签收次日起算。

## 五、退款规则

- 退款路径：**原路退回**至原支付账户。
- 发起时间：退货质检通过后 **1-3 个工作日**内发起退款。
- 到账时间：微信、支付宝 **1-3 个工作日**；银行卡 **3-7 个工作日**。
- 退款金额：商品实付金额 + 商家承担的运费；买家原因产生的运费不退。
- 优惠券：整单退款且在有效期内的券会返还；部分退款不返还优惠券。

## 六、换货流程

1. 在订单详情提交换货申请，选择换货原因并上传凭证。
2. 商家 **24 小时内**审核。
3. 审核通过后按指引寄回商品。
4. 仓库 **48 小时**内完成质检。
5. 质检通过后发出新商品，换货物流单号会同步到订单。

## 七、不支持退货的情形

- 超过退货期限的商品。
- 人为损坏、进水、摔损、私自拆修的商品。
- 缺少配件、说明书、赠品未退回的商品。
- 定制类商品、已使用的虚拟商品。
- 生鲜商品（坏果包赔除外，见运费与配送规则）。
