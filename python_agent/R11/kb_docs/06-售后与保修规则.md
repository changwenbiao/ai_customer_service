# 售后与保修规则

## 一、保修期限

- 手机及数码产品：**1 年**。
- 大家电：整机 **1 年**，主要部件 **3 年**。
- 小家电：**6 个月**。
- 保修期自签收次日起算。

## 二、保修凭证

- 凭订单号即可享受保修，**无需纸质发票**。
- 订单丢失：可提供下单手机号后四位 + 收货人姓名查询。

## 三、维修流程

1. 在线提交维修申请并描述故障。
2. 选择寄修或上门维修（大家电支持上门）。
3. 维修完成后 **7 个工作日**内寄回或上门完成。
4. 维修超过 **30 天**未修复，可申请换新。

## 四、以旧换新

- 支持品类：手机、平板、大家电。
- 估价流程：线上预估 → 寄出旧机 → 质检确认 → 抵扣新机款。
- 差价处理：质检价高于预估则补差给用户；低于预估则多退少补。
- 取消规则：质检后取消订单，旧机寄回运费由用户承担。

## 五、安装服务

- 大家电免费基础安装。
- 高空作业费：**3 层及以上每层 100 元**。
- 加长管线：超出标配 **3 米**的部分按 **50 元/米**收费。
- 安装预约：付款后可在订单详情预约，**48 小时内**联系上门。

## 六、保修不适用情形

- 人为损坏、进水、摔损。
- 私自拆机或非官方渠道维修。
- 超出保修期限。
- 非官方渠道购买的商品。
