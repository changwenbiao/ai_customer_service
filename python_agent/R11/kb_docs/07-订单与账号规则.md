# 订单与账号规则

## 一、订单状态

订单状态依次为：待付款 → 待发货 → 已发货 → 已签收 → 已完成。
异常状态：已取消、退款中、退款完成。

## 二、取消订单

- 待付款：可直接取消，无任何费用。
- 待发货：可自助取消，退款 **1-3 个工作日**原路退回。
- 已发货：无法直接取消，需拒收或签收后申请退货。
- 已签收：走退换货流程。

## 三、修改收货地址

- 发货前：可修改 **1 次**收货地址。
- 偏远地区订单：发货前不支持修改地址。
- 已发货：需联系快递改派，可能产生改派费用。
- 修改地址不影响订单价格与优惠。

## 四、合并与拆分

- 不同订单不支持合并支付。
- 同一仓库商品可合并发货。
- 不同仓库商品自动拆单发货，物流单号分别推送。
- 拆单不影响退换货政策，按商品分别计算期限。

## 五、账号安全

- 换绑手机号：需原手机号接收验证码，**24 小时内**生效。
- 注销账号：提交后有 **7 天冷静期**，期间可撤回；注销后订单记录保留 6 个月。
- 账号被盗：立即冻结账号并联系人工客服，**2 小时内**响应。

## 六、订单查询

- 查询方式：订单号，或下单手机号后四位 + 收货人姓名。
- 代下单：需提供下单人手机号后四位验证。
- 隐私保护：客服不会向第三方透露订单收货地址与联系方式。
