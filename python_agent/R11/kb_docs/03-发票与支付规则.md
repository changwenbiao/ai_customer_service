# 发票与支付规则

## 一、发票类型

- 电子普通发票：默认开具，订单完成后可自助申请。
- 增值税专用发票：需上传一般纳税人资质证明，**3 个工作日内**审核。

## 二、开票时间与修改

- 申请时间：订单完成后 **30 天内**可申请开票。
- 开具时间：开票申请通过后 **1-3 个工作日**内发送至预留邮箱。
- 重开规则：已开票 **30 天内**可重开 **1 次**；跨月不可更改发票抬头。
- 发票内容：默认按商品明细开具，不支持开具非商品类目。

## 三、支付方式

- 支持微信支付、支付宝、银联在线、信用卡。
- 信用卡分期：3 期手续费 **1.8%**、6 期 **3.6%**、12 期 **7.2%**，手续费由银行收取。
- 不支持货到付款。

## 四、支付异常

- 未支付订单：下单后 **30 分钟**自动取消并释放库存。
- 重复支付：核实后 **1-3 个工作日**原路退回多付金额。
- 支付成功但订单未生成：保留支付凭证联系客服，**24 小时内**处理。

## 五、价格保护

- 申请条件：签收后 **7 天内**，同一商品同一规格出现降价。
- 退还方式：退还差价，原路退回。
- 不参与价保：限时秒杀、直播专享价、优惠券或满减导致的价差、赠品变化、不同店铺比价。
- 申请入口：订单详情页 - 价格保护。

## 六、支付安全

- 平台不会以任何理由索要支付密码、短信验证码。
- 客服不会引导用户到平台外进行转账。
- 发现异常扣款，可申请交易核查，**48 小时内**反馈结果。
