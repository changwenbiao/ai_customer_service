# 运费与配送规则

## 一、包邮规则

- 单笔订单实付满 **99 元**包邮。
- 实付不满 99 元收取基础运费 **8 元**。
- 不包邮地区：新疆、西藏、内蒙古、青海、宁夏。上述地区首重 **12 元**，续重 **8 元/公斤**。
- 大家电等大件商品免运费，安装费按安装服务规则另计。

## 二、发货时效

- 现货商品：付款后 **48 小时内**发货。
- 预售商品：按商品详情页承诺的时间发货，最长不超过 **15 天**。
- 大促期间（618、双 11 等）：**72 小时内**发货。

## 三、配送时效

- 华东、华南、华北地区：**1-3 天**送达。
- 偏远地区：**5-7 天**送达。
- 遇恶劣天气、疫情管控等不可抗力，配送时效顺延，平台会通过短信通知。

## 四、物流异常处理

- **48 小时无揽收记录**：可申请催发，或直接申请退款。
- 超过承诺时效 **7 天**仍未送达：可申请补发或全额退款。
- 包裹丢失或破损：由商家承担责任，可选择重新发货或全额退款。
- 物流停滞超过 3 天：客服可代为发起物流查询工单。

## 五、拒收与拦截

- 无理由拒收：往返运费由买家承担。
- 发货前拦截：免费，订单金额原路退回。
- 已发货后拦截：需联系快递，产生的拦截费用由买家承担。

## 六、生鲜配送

- 坏果包赔：签收后 **48 小时内**拍照申请，按坏果比例赔付。
- 生鲜商品不支持 7 天无理由退货。
- 生鲜商品因买家原因放置过久导致变质，不予赔付。
