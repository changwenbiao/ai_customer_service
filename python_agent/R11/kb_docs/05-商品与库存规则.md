# 商品与库存规则

## 一、预售规则

- 定金规则：定金 **100 元抵扣 300 元**，具体以商品页为准。
- 尾款时间：按商品页公示时间支付尾款。
- 逾期未付：订单自动取消，**定金不退**（商品页已明示）。
- 预售商品发货：尾款支付后按预售承诺时间发货，最长 15 天。

## 二、库存规则

- 锁库存：下单后锁定库存 **15 分钟**，超时未支付自动释放。
- 缺货处理：付款后 **48 小时内**确认缺货的，主动取消订单并补偿 **5 元无门槛券**。
- 限购：秒杀商品每账号每场限购 **1 件**。
- 超卖：因系统原因超卖的订单，平台优先补货；无法补货的全额退款并额外补偿 10 元券。

## 三、正品保障

- 官方旗舰店及自营商品：**假一赔十**。
- 第三方店铺商品：由平台监管，支持 7 天无理由退货。
- 疑似假货：可申请鉴定，鉴定费用由平台先行承担，鉴定为假货的由商家承担并赔付。

## 四、价格展示

- 划线价：为厂商指导价或历史成交价，仅供参考。
- 实际成交价：以结算页最终金额为准。
- 价格差异：不同渠道、不同活动价格可能不同，以下单时价格为准。

## 五、商品信息

- 商品参数以详情页为准，图片因拍摄光线可能存在色差。
- 尺码建议：服装类提供尺码表，误差 ±2cm 属正常范围。
- 商品咨询：可由 AI 客服查询库存与参数，不承诺具体到货时间。
